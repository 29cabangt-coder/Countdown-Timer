## Description

A small, mobile-friendly countdown timer that lets you set a duration in minutes and seconds, then start a timer in your web browser.

## How to Run

1. Clone or download the project.
2. Open `index.html` in a web browser.

## Features

- Set a countdown from 1 second up to 999 minutes and 59 seconds.
- Start, pause, resume, and reset the timer.
- Use the responsive, touch-friendly interface on a cellphone.
- Get a message when the countdown reaches zero.
